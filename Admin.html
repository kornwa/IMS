💬 LINE Messaging API แนะนำ
📌 วิธีตั้งค่า:
1. ไป LINE Developers Console → Login
2. Create Provider → Create Messaging API Channel
3. แท็บ Messaging API → คัดลอก Channel access token (long-lived)
4. ผู้ใช้ Add เพื่อน OA → ระบบ broadcast ส่งหาทุกคนที่เป็นเพื่อน
💰 ฟรี 200 ข้อความ/เดือน
🎮 Discord Webhook ฟรีไม่จำกัด
📌 วิธีตั้งค่า:
1. เปิด Discord → Server Settings → Integrations → Webhooks
2. New Webhook → ตั้งชื่อ + เลือกห้อง → Copy Webhook URL
3. วาง URL ด้านล่างแล้วบันทึก

🔗 Webhook URL สำหรับ LINE Bot (Console → Messaging API → Webhook URL)
